# हिंदी चुटकुला जनरेटर

एक सुंदर और इंटरैक्टिव वेब ऐप जो बाहरी JokeAPI से मज़ेदार चुटकुले लाता है।

## फीचर्स
- हिंदी + English भाषा टॉगल
- मज़ेदार, व्यंग्य, प्रोग्रामिंग, रैंडम moods
- रिजल्ट में श्रेणी चुनने की सुविधा
- अगला मज़ा बटन
- कॉपी और शेयर बटन
- पसंदीदा सूची (localStorage में सेव)
- हालिया इतिहास
- ऑटो रिफ्रेश विकल्प
- लाइट/डार्क थीम
- पसंद / नापसंद रेटिंग

## API
यह ऐप JokeAPI का उपयोग करता है:
- https://v2.jokeapi.dev/

## कैसे चलाएँ
1. इस फ़ोल्डर को खोलें
2. लोकल सर्वर शुरू करें:

```bash
python -m http.server 8000
```

3. ब्राउज़र में जाकर खोलें:

```bash
http://localhost:8000
```

## फ़ाइलें
- `index.html` – मुख्य UI
- `style.css` – चमकदार छवि और लेआउट
- `script.js` – API, लोकल स्टोरेज, पसंदीदा, इतिहास और ऑटो रिफ्रेश लॉजिक

## नोट
अगर API से प्रतिक्रिया नहीं मिलती है, तो ऐप अपने internal fallback jokes से काम करेगा ताकि UI ठीक रहे।
