# हिंदी चुटकुला जनरेटर

एक सुंदर और इंटरैक्टिव वेब ऐप जो बाहरी joke API से मज़ेदार चुटकुले लाता है।

## सुविधाएँ
- हिन्दी इंटरफ़ेस
- श्रेणी चुनने की सुविधा
- अगला चुटकुला जनरेट करने वाला बटन
- कॉपी बटन
- डार्क/लाइट थीम टॉगल
- रेस्पॉन्सिव UI

## API
यह ऐप JokeAPI का उपयोग करता है:
- https://v2.jokeapi.dev/

## कैसे चलाएँ
1. `index.html` फ़ाइल को अपने ब्राउज़र में खोलें
2. या लोकल सर्वर चलाएँ:

```bash
python -m http.server 8000
```

फिर ब्राउज़र में खोलें:

```bash
http://localhost:8000
```

## फ़ाइलें
- `index.html` – UI
- `style.css` – स्टाइलिंग
- `script.js` – API कॉल और कॉपी/थीम लॉजिक
