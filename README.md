# हँसी अड्डा — हिंदी चुटकुले

कॉलेज, टेक, घर-परिवार, दोस्ती और रोज़मर्रा की देसी ज़िंदगी पर आधारित मौलिक हिंदी चुटकुलों का छोटा वेब ऐप। चुटकुले ऐप में ही मौजूद हैं, इसलिए उन्हें देखने के लिए इंटरनेट या किसी बाहरी API की ज़रूरत नहीं है।

## फीचर्स
- श्रेणी के अनुसार हिंदी चुटकुले
- पसंदीदा चुटकुले और हाल में सुने चुटकुले
- चुटकुला फिर से सुनने के लिए सूची में चुनना
- शेयर करना; जहाँ शेयर सुविधा उपलब्ध न हो, वहाँ शेयर करने के लिए कॉपी करना
- लाइट/डार्क थीम
- पसंदीदा, इतिहास और थीम को ब्राउज़र में सहेजना

## कैसे चलाएँ
1. इस फ़ोल्डर को VS Code में खोलें।
2. लोकल सर्वर शुरू करें:

```bash
python -m http.server 8000
```

3. ब्राउज़र में जाकर खोलें:

```bash
http://localhost:8000
```

## फ़ाइलें
- `index.html` – हिंदी इंटरफ़ेस
- `style.css` – ऐप की स्टाइल और मोबाइल लेआउट
- `script.js` – स्थानीय चुटकुले, पसंदीदा, इतिहास, शेयर और थीम
